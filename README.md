# Portal de Notícias

Este projeto é um site pessoal que apresenta meus projetos e habilidades. Foi desenvolvido utilizando HTML, CSS e JavaScript.

## Descrição Detalhada

Esse projeto conta com uma contrução semântica de HTML e criação estrutural incrível em CSS, onde é permitido fazer alterações rápidas, tornando o trabalho mais objetivo e preciso.
